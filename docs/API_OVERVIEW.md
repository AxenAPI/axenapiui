# Обзор API бэкенда

Этот документ описывает ключевые группы эндпоинтов, предоставляемые локальным Java-сервисом, которые используются фронтендом для выполнения всех основных операций.

## Управление EventGraph (`/EventGraph`)

- Создание и модификация графа событий (`EventGraphDTO`).
- Добавление сервисов из спецификаций.
- Расчет путей между узлами графа.
- Получение и обновление спецификаций для отдельных сервисов.

## Генерация Документации и Кода (`/Documentation`)

- Генерация спецификаций OpenAPI (`JSON`, `YAML`).
- Генерация клиентского и серверного кода.
- Создание документации в форматах `Markdown`, `DOCX`, `PDF`.
- Управление страницами документации (создание, удаление, перемещение, переименование).

## Утилиты для JSON (`/JSON`)

- Генерация примеров JSON из JSON Schema.
- Генерация JSON Schema из JSON-объекта.

## Интеграция с Git (`/Git`)

- Управление локальными репозиториями (CRUD).
- Работа с ветками (создание, переключение).
- Выполнение базовых Git-операций: `add`, `commit`.
- Создание Merge Request.
- Получение статуса репозитория.

## Управление Брокерами (`/Brokers`)

- CRUD-операции для конфигураций брокеров сообщений (Kafka, JMS, RabbitMQ).

## Загрузки (`/download`)

- Эндпоинты для скачивания сгенерированных артефактов (спецификаций, документации).

## Проверка Состояния (`/health`)

- Эндпоинт для проверки работоспособности сервиса.
