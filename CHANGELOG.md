## [2.6.0]

### Changed

- Проект полностью переведен на **ES Modules** (`"type": "module"`), что является современным стандартом JavaScript.
- Скрипты обновления артефактов и генерации API улучшены: теперь они корректно сравнивают версии и не выполняют лишних обновлений.
- **Оптимизация загрузки:** Улучшена логика запуска приложения — теперь фронтенд ожидает полной готовности бэкенда, что устраняет ошибки "раннего запроса".
- **Индикация загрузки:** Доработана и улучшена полоса загрузки приложения.

### Added

- Внедрена последняя версия **ESLint v9** с новой системой "flat config" (`eslint.config.js`) для улучшения качества кода.
- Создана и настроена директория `common` для хранения общего кода (типов и констант) между `node` и `web` контекстами.
- **Поиск по документации:** Реализована функциональность полнотекстового поиска по содержимому документов.
- **Интеграция с таск-трекером:** Добавлена возможность связывать репозиторий документации с проектом в таск-трекере.
- **Управление документами в моделере:**
  - Просмотр документов, привязанных к узлам графа.
  - Механизм привязки документов к узлам.
- **Управление тегами:** Добавлен режим просмотра и редактирования тегов для узлов графа.

### Refactored

- Проведен масштабный **архитектурный рефакторинг** для полной изоляции `node` (Electron) и `web` (React) контекстов.
- Полностью переработана структура `tsconfig` файлов для обеспечения строгой изоляции и надежности.

### Fixed

- Устранены все ошибки компиляции `TypeScript`.
- Устранены все ошибки `runtime` при запуске приложения, связанные с переходом на ESM.
- Исправлено множество ошибок и предупреждений `ESLint` в соответствии с новыми правилами.
- **Типизация:** Исправлены типы данных (`GitRepoDto`) на стороне фронтенда для корректного взаимодействия с API.
- **Импорт wiki-страниц:** Устранена ошибка в библиотеке импорта из Yandex Wiki.

## [1.0.0]

### Added

- **Визуализатор графа:** Реализован основной функционал отображения графа событий из JSON на базе `React-Flow`.
- **Управление нодами:** Добавлена возможность создавать, редактировать, удалять и связывать различные типы узлов ( Service, Topic, HTTP).
- **Интерактивность:**
  - Создание связей перетаскиванием.
  - Контекстные меню для элементов графа и сайдбара.
  - Автоматическое выравнивание графа с помощью `elkjs`.
- **Интерфейс:**
  - Разработаны основные элементы управления: хедер с кнопками, сайдбар с деревом элементов, информационная панель.
  - Реализован вкладочный интерфейс для переключения между разными представлениями.
  - Добавлен механизм уведомлений.

- **Спецификации:** Добавлен функционал для работы со спецификациями, включая их экспорт.
- **Раздел документации:** Создан раздел для ведения документации с поддержкой `MDX`, `Mermaid` и `PlantUML`.
- **Поиск:** Реализован поиск по элементам в сайдбаре.
- **Git-интеграция:** Добавлены базовые функции для работы с Git в разделе документации.
- **Экран загрузки:** Добавлен экран-заставка, отображаемый до полной готовности бэкенда.
