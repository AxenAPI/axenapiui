# Скрипт обновления артефактов (`update-artifacts`)

## 1. Назначение

Этот скрипт автоматизирует процесс скачивания и установки свежих версий артефактов, необходимых для работы приложения:

- `axenapi-web-*.jar`: Основной исполняемый файл бэкенда.
- `*.yaml`/`*.yml`: Файлы OpenAPI схем.

Скрипт находит последнюю `SNAPSHOT`-версию в Nexus-репозитории, сверяет ее с локально установленной и при необходимости обновляет артефакты.

## 2. Перед использованием

Для работы скрипта требуется доступ к внутреннему Nexus-репозиторию. Убедитесь, что вы подключены к корпоративной сети (например, через VPN).

Также необходимо создать файл `.env.loc` в корне проекта и указать в нем ваши учетные данные для Nexus:

```dotenv
# .env.loc
NEXUS_USERNAME=your_login
NEXUS_PASSWORD=your_password
```

## 3. Команды

Для удобства в `package.json` добавлены следующие команды:

- `yarn update-artifacts`
  - Основная команда. Обновляет и JAR, и схемы.
- `yarn update-artifacts:jar`
  - Обновляет только JAR-файл.
- `yarn update-artifacts:schema`
  - Обновляет только файлы схем.

## 4. Опции

Командам можно передавать дополнительные флаги:

- `--force`
  - Принудительно скачивает и устанавливает артефакты, даже если локальные версии считаются актуальными.
  - _Пример:_ `yarn update-artifacts --force`

- `--dry-run`
  - "Пробный запуск". Скрипт выполняет все проверки, но не скачивает и не изменяет файлы. Показывает, какие действия были бы выполнены.
  - _Пример:_ `yarn update-artifacts --dry-run`

## 5. Как это работает

1.  **Парсинг аргументов**: Скрипт определяет, какие артефакты обновлять (`jar`, `schema`, `all`) и какие флаги (`force`, `dry-run`) используются.
2.  **Поиск в Nexus**:
    - Определяется `major.minor` версия проекта из `package.json`.
    - В Nexus ищется последняя `SNAPSHOT`-версия, соответствующая этому префиксу (например, для `2.6.x` ищется `2.6.0-SNAPSHOT`).
    - Для найденной SNAPSHOT-версии ищется последняя по времени сборка, которая содержит и `.jar`, и `.zip` файлы.
3.  **Сравнение версий**:
    - Скрипт читает имена последних успешно установленных артефактов из файлов-меток `.version-jar` и `.version-schema`.
    - Сравнивает их с именами найденных в Nexus.
4.  **Обновление**:
    - Если версии отличаются (или использован флаг `--force`), запускается процесс обновления.
    - **JAR**: Скачивается во временный файл, затем атомарно заменяет старый. Старые `.jar` файлы удаляются.
    - **Схемы**: Скачивается `.zip` архив, все старые `.yaml` файлы в папке `openapi` удаляются, а новые распаковываются из архива.
5.  **Обработка ошибок**:
    - В случае сбоя сети скрипт проверяет, есть ли локально установленные артефакты, и предлагает продолжить работу с ними.
