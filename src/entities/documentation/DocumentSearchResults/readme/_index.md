# Epic: Document Search

## 1. Цель и контекст

### 1.1. Описание эпика

Реализовать функциональность полнотекстового поиска по файлам документации в Git-репозитории. Пользователь должен иметь возможность ввести поисковый запрос, увидеть список релевантных документов и перейти к выбранному документу. Эта фича призвана кардинально улучшить навигацию и юзабилити раздела "Документация", особенно в крупных проектах.

### 1.2. Ожидаемый результат

- На странице "Документация" над деревом файлов присутствует поле для ввода поискового запроса.
- При вводе запроса (с debounce-логикой) отправляется запрос на бэкенд.
- Вместо дерева файлов отображается список найденных документов.
- Если ничего не найдено, отображается соответствующее сообщение.
- При клике на документ из списка он открывается в редакторе.
- При очистке поля поиска или нажатии на "крестик" список результатов скрывается, вновь отображается дерево файлов, в котором подсвечен текущий открытый документ.
